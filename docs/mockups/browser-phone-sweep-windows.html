Close all other windows

One action collapses every Chrome window into the one you are driving: the agent page stays connected, everything else closes, and one blank page is left open. The frames below reuse the shipped sheet — same 22 px radius, 56 px chip rail, WINDOWS / TABS kickers, Size & Capture footer, and the existing close-window dialog shell.

Where it lives

Bottom of the window rail, in one slot for both rail states: a 40 × 38 red × when collapsed, a labelled row when open. It is window-scoped, so it belongs beside the window list — not in the sheet header with the page actions, and not in the tab header.

Which window survives

The window you are already driving (the one holding this session's /go page). No re-attach and no SwitchSession, so the mirror never jumps mid-sweep.

What stays in it

Every /go?session= tab — running agents stay connected — plus one fresh about:blank opened active. Every other tab of that window closes, including the page you were looking at.

What closes

Every other drivable window (normal, popup, app) with all of its tabs. devtools windows are never touched, and Chrome's last window is never closed, so the sweep can never leave the browser windowless.

Numbers are real

The ledger is computed from one window listing taken when the dialog opens, so the copy and the confirm label always match what will happen (3 → 1, Close 2 windows).

Gated, never silent

Same blocker as closing one window: browser-agent 1.0.22+, not read-only, nothing in flight, and at least two windows. Otherwise the control is disabled with one line of reason.
