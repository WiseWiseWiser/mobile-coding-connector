主页信息架构

  • Hero 名称 + pid/user/state + 保护/tunnel 标签
  • Tiles CPU（本进程）/ RSS；旁注 tree Σ CPU（自己+子孙）
  • Command 全文换行 + Copy
  • Identity pid, ppid, user, state, elapsed, protected reason
  • Parent 可点卡片 → 父 PID 主页（launchd/pid 1 也可进，Kill 在页上锁住）
  • Children ppid==this 的列表；空则 “No child processes”
