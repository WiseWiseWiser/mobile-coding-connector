机制

  • Kill：createPortal(modal, document.body)，避开 .mcc-tab-content 的 overflow / iOS fixed 陷阱。
  • Lock：lockedPids: number[] | null 仅 React state。刷新/进 PID 页再返回可丢（仅 mem）。新 pid 追加在末尾，消失的拿掉。
  • Pause 停轮询；Lock 不停轮询、只冻顺序。两者独立。
